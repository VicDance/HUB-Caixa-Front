# HUB-Caixa-Front

## Project Overview
The goal of this project was to create a fluid user experience while maintaining a clean, scalable codebase.

## Tech Stack
- Core: React 19 (Vite) + TypeScript
- Routing: React Router v7
- Styling: Tailwind CSS
- Testing: Vitest + React Testing Library + JSDOM

## Getting Started
### Installation
- git clone https://github.com/VicDance/HUB-Caixa-Front.git
- cd HUB-CAIXA-FRONT
- npm install

### Development
- npm run dev   # Start development server
- npm run test  # Run the test suite
